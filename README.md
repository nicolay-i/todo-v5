# Дерево задач

Интерфейс для управления задачами с вложенностью до трёх уровней. Приложение на Next.js с серверным бэкендом на Prisma/SQLite, поддерживает перетаскивание элементов между уровнями и аккуратный светлый интерфейс на Tailwind CSS.

## Возможности
- вложенные задачи до трёх уровней глубины;
- drag-and-drop сортировка и перемещение между уровнями;
- добавление, редактирование, удаление элементов;
- отметка задач как выполненных и снятие отметки;
- минималистичный светлый дизайн с иконками вместо текстовых кнопок;
- закреплённые слоты (например, на дни) с возможностью сворачивания/разворачивания.
- авторизация через Telegram и изоляция данных пользователей.

## Технологии
- Next.js 14 + TypeScript;
- Prisma ORM с SQLite;
- MobX для клиентского состояния;
- Tailwind CSS для стилизации;
- HTML5 drag-and-drop.

## Быстрый старт

```bash
# Установите зависимости
pnpm install

# Настройте переменные окружения
cp .env.local.example .env

npx prisma db push  # создаст SQLite файл и таблицы

# Запустите dev-сервер
pnpm dev
```

Приложение будет доступно на `http://localhost:3000`.

## Авторизация через Telegram

Каждый пользователь входит в приложение через Telegram. После успешной авторизации данные задач и закреплённых списков доступны только владельцу.

1. Создайте Telegram-бота через BotFather и получите токен и числовой идентификатор бота.
2. Укажите значения `TELEGRAM_BOT_ID` и `TELEGRAM_BOT_TOKEN` в файле `.env` (см. `.env.example`).
3. Перезапустите dev-сервер, чтобы изменения переменных окружения вступили в силу.

При выходе из аккаунта сессия удаляется и cookie очищается.

## Полезные скрипты

### Основные команды
- `pnpm dev` — запуск дев-сервера;
- `pnpm build` — сборка production-версии;
- `pnpm start` — запуск собранного приложения;
- `pnpm check` — проверка типизации кода.

### Управление базой данных
- `pnpm db:push` — синхронизация схемы БД без миграций (для разработки);
- `pnpm db:migrate:dev` — создание и применение миграций;
- `pnpm db:studio` — запуск Prisma Studio для визуального просмотра БД.

### Переключение между SQLite (dev) и PostgreSQL (prod)
Проект поддерживает различные структуры/набора миграций для dev и prod окружений.

Скрипт `scripts/switch-db.js` (обёрнут в команды ниже) обновляет:
1. `datasource db` блок между маркерами `DATASOURCE_START/END`;
2. Путь для генерации миграций в `generator client` (строка `migrations = ...`).

Директории:
- dev (SQLite): `prisma/migrations-sqlite`
- prod (PostgreSQL): `prisma/migrations`

Команды:
```bash
pnpm db:dev   # переключение на SQLite (dev), migrations -> prisma/migrations-sqlite
pnpm db:prod  # переключение на PostgreSQL (prod), migrations -> prisma/migrations
```

После переключения можно создавать миграции, и они лягут в соответствующую директорию.
Важно: не редактируйте вручную путь миграций и datasource — они будут перезаписаны скриптом.

## Перетаскивание
Перетаскивание реализовано на чистом HTML5 drag-and-drop. Доступные точки сброса отображаются только во время перетаскивания и учитывают ограничения по глубине вложенности.

## Сворачиваемые слоты на день
- В заголовке слота доступна кнопка со стрелкой для сворачивания/разворачивания списка задач.
- Число рядом с названием показывает количество задач в слоте.
- Состояние свёрнутости сохраняется локально (localStorage) и восстанавливается при перезагрузке страницы.

## Навигация по вкладкам через URL
Активная вкладка интерфейса синхронизируется с параметром URL `?tab=`. Поддерживаемые значения:
- `pinned` — Слоты;
- `all` — Список задач;
- `settings` — Настройки.

Примеры:
- `http://localhost:3000/?tab=all` — открыть страницу со вкладкой «Список задач»;
- навигация «Назад/Вперёд» корректно восстанавливает активную вкладку.

## Клавиатурные сокращения

Краткая справка по добавленным горячим клавишам (работают, когда фокус не внутри поля ввода или кнопки):

- N — открыть модал добавления новой задачи (вкладка «all»).
- Alt + ← / Alt + → — переключить вкладки (pinned ↔ all ↔ settings).
- Alt + ↑ / Alt + ↓ — шаг по закреплённым спискам (на вкладке `pinned`).
- ↑ / ↓ — перейти к предыдущей/следующей задаче (когда фокус на пустой странице — фокус ставится на крайний элемент списка).

На карточке задачи (когда карточка в фокусе):

- ↑ / ↓ — вверх/вниз по списку задач.
- Home / End — к первому/последнему элементу в текущем scope (list или pinned).
- ← / → — свернуть/развернуть узел (если есть дети).
- Пробел — отметить/снять отметку выполнения.
- Delete / Backspace — удалить задачу.
- E — войти в режим редактирования названия.
- A — открыть/закрыть форму добавления подзадачи.
- T — открыть/закрыть меню тегов; Shift+T — быстро прикрепить/открепить тег.

В меню тегов:

- ↑ / ↓, Home / End — навигация по элементам.
- 1..9 — выбрать тег по позиции.
- Esc — закрыть меню и вернуть фокус на карточку.

Редактирование и формы:

- Esc — отменить редактирование или закрыть модал/форму.
- Enter / Ctrl+Enter (или Meta+Enter) — сохранить изменения (в многострочном вводе использовать Ctrl/Meta+Enter для сохранения).
