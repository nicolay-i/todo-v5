Mind Map Viewer

Отображает актуальные данные mind map непосредственно из PostgreSQL с расширением pgvector. На странице используется TailwindCSS и визуализация обновляется в реальном времени.

Нет данных

Mind map пока пустая. Отправьте данные на POST /api/mind-map, чтобы увидеть визуализацию.

Журнал событий

История создания и обновления mind map. Список обновляется автоматически.

API

GET /api/mind-map — список нод, связей и журналов.

POST /api/mind-map — синхронизация данных mind map.

GET /api/mind-map/logs — последние события.
